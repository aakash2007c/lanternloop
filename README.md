# Lantern Loop — Game Design Document and Playable Prototype

A small original browser game made for the beginner Game Development task.

## Run it
Open `index.html` in a modern browser. No installation, server, account, or external assets are needed.

## Files
- `index.html` — playable prototype (keyboard and touch controls)
- `Game-Design-Document.md` — one-page GDD
- `Playtest-Sheet.md` — observations and retest template
- `main-screen-sketch.svg` — simple screen / feedback-state sketch

## Controls
WASD / arrow keys to move, Space to pause. On mobile, use the directional buttons. Click Start / Restart to begin.

## To submit one public/view-only link
Upload these files to a GitHub repository and enable GitHub Pages (Settings → Pages → deploy from the main branch/root). The resulting Pages URL opens the playable prototype; the same repository contains the GDD and playtest sheet. Alternatively, upload the folder to a view-only cloud folder, but that will not run the game directly.
