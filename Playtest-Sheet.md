# Lantern Loop — Playtest Sheet

Do not collect unnecessary personal data. Ask the tester to play without explaining the rules beyond the opening screen.

| Test | Observation |
|---|---|
| Did the player understand the goal without help? | |
| Time until first successful firefly collection | |
| Did the player notice score, timer, and lives? | |
| Where did the player lose a life or get confused? | |
| Did the controls feel responsive on their device? | |
| Delight / frustration moment | |
| One change to make and retest | |

## Example test plan
1. Give the player the link or open `index.html`.
2. Say only: “Please play this and tell me what you think.”
3. Observe silently for 1–2 minutes.
4. Ask: “What was your goal? What felt confusing? What one change would help?”
5. Make one change and test again.
